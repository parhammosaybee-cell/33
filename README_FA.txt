PM Chat — چت عمومی با تعویض عکس پروفایل

Build Command: pip install -r requirements.txt
Start Command: uvicorn main:app --host 0.0.0.0 --port $PORT

این نسخه امکان انتخاب عکس JPG/PNG/WEBP/GIF تا ۳ مگابایت و نمایش آن کنار پیام‌ها را اضافه می‌کند. عکس‌ها و SQLite روی دیسک محلی ذخیره می‌شوند؛ برای ماندگاری در Render باید Persistent Disk متصل شود و مسیر /opt/render/project/src/data را به آن بدهی (یا مسیر مطابق Root Directory پروژه). نام کاربری هنوز احراز هویت امن نیست و امکان جعل نام وجود دارد؛ این برنامه برای انتشار عمومی هنوز به ثبت‌نام امن، محدودیت ارسال و مدیریت سوءاستفاده نیاز دارد.
